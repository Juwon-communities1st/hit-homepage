# HIT homepage mockup — Living Archive

A proposed homepage design for Herts Inclusive Theatre (HIT), built to WCAG 2.1 AA with dyslexia-friendly typography.

This is a design mockup for review, not the live HIT website. Testimonials are sample wording and most photos are placeholders.
